# Binary Number Generator

A simple Java Swing-based GUI application to generate binary numbers up to a given decimal input.

## 📸 Screenshot

![BinaryNumberGenerator](https://github.com/user-attachments/assets/e633d6a3-b6f6-4fee-b03e-e036a8d64b19)
(BinaryNumberGenerator.png)

## 🚀 Features

- User-friendly graphical interface (built using Java Swing)
- Input any decimal number
- Generates and displays all binary numbers from 1 up to the input number

## 🛠️ Built With

- Java
- Swing (GUI)
- `.jar` executable packaged with `manifest.txt`
